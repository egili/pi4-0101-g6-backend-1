# CT10 – Tabela credencial

## Cabeçalho

| Campo | Valor |
|---|---|
| **ID e nome** | CT10 – Tabela `credencial` |
| **Fronteira** | Banco |
| **Quem chama** | Servidor |
| **Quem responde** | Banco de Dados |
| **Atende** | E4, E5, E6, E8, E9 |
| **Como chamar** | Tabela `credencial` no SQLite |

## Entrada

| Campo | Tipo | Obrigatório | Exemplo |
|---|---|---|---|
| `id` | inteiro | Sim (auto) | `10` |
| `usuario_id` | inteiro | Sim | `1` |
| `servico` | texto | Sim | `Gmail` |
| `usuario_servico` | texto | Sim | `eliseu@gmail.com` |
| `dados_cifrados` | texto | Sim | `U2FsdGVkX1+...` |
| `iv` | texto | Sim | `3a4b5c6d7e8f...` |
| `criado_em` | data e hora | Sim | `2026-10-13T19:20:00` |
| `atualizado_em` | data e hora | Sim | `2026-10-13T19:20:00` |

## Saída

| Campo | Tipo | Obrigatório | Exemplo |
|---|---|---|---|
| `id` | inteiro | Sim | `10` |
| `usuario_id` | inteiro | Sim | `1` |
| `servico` | texto | Sim | `Gmail` |
| `usuario_servico` | texto | Sim | `eliseu@gmail.com` |
| `dados_cifrados` | texto | Sim | `U2FsdGVkX1+...` |
| `iv` | texto | Sim | `3a4b5c6d7e8f...` |
| `criado_em` | data e hora | Sim | `2026-10-13T19:20:00` |
| `atualizado_em` | data e hora | Sim | `2026-10-13T19:20:00` |

## Erros

| Quando | O que volta |
|---|---|
| `usuario_id` não existe na tabela `usuario` | `FOREIGN_KEY_VIOLATION` |
| Campo obrigatório vazio | `NOT_NULL_VIOLATION` |
| Erro de escrita no arquivo | `SQLITE_IOERR` |
